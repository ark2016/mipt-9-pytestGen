# pytestgen

LLM-assisted генератор pytest-тестов для Python-модулей: статический анализ (`ast`), concolic-lite
поиск путей (AST + Z3), запись фактического поведения в изолированной песочнице, LLM для заполнения
слотов шаблона (ревью оракулов, входы для нерешённых веток, свободные тесты), цикл исправления по
traceback и отчёт о приросте покрытия.

> Работа в процессе. Полная документация (архитектура, запуск одной командой, ограничения) появится
> по мере готовности этапов.

## Разработка

```bash
uv sync                      # окружение + dev-зависимости
uv run pre-commit install    # хуки: ruff, mypy, uv-lock
uv run pytest -m "not slow" --cov=pytestgen
uv run pytestgen --help
```

Конфигурация — переменные окружения `PYTESTGEN_*`, см. [`.env.example`](.env.example).
