# 0008. `--minimize` опционален

Статус: принято.

## Контекст

Часть сгенерированных тестов не добавляет покрытия: дубли граничных значений, лишние
предложения модели. Выбрасывать их можно только пробным удалением с повторным прогоном в
песочнице - это стоит запуска pytest на каждого кандидата.

## Решение

Минимизация выключена по умолчанию и включается флагом `--minimize`
(`SuiteSelector.minimize`).

- Жадно перебираются free-form тесты и кейсы с источником `llm_slot` (последние первыми); тест
  удаляется, если без него выполняются все прежние строки и дуги и набор остаётся зелёным.
- Кейсы от Z3 не удаляются: они дёшевы и документируют каждую ветку.
- Бюджет - `PYTESTGEN_MAX_MINIMIZE_RUNS` (12) пробных прогонов; на больших наборах минимизация
  частичная.
- Удалённые тесты попадают в отчёт с причиной `no_coverage_gain`.

## Последствия

- Быстрый путь по умолчанию: пользователь получает все проверенные тесты. Они хороши и как
  регрессионные, даже когда покрытие не растёт.
- Минимизация для тех, кому нужен компактный файл; её цена ограничена бюджетом.
- Результат жадный, не оптимальный: порядок перебора влияет на то, что останется.
