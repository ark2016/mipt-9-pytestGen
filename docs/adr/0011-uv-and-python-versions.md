# 0011. uv, Python 3.12 в Docker и CI, поддержка >= 3.11

Статус: принято.

## Контекст

Нужны воспроизводимые окружения для разработчика, CI и Docker, быстрая установка и
фиксированные версии зависимостей (в том числе тяжёлого `z3-solver`). Проект должен
работать и на не самой свежей версии Python.

## Решение

- Менеджер проекта - `uv`: `pyproject.toml` + `uv.lock`, везде `uv sync --frozen`,
  версия uv зафиксирована (0.9.17 в Dockerfile и в `action.yml`). CI проверяет `uv lock --check`.
- `requires-python = ">=3.11"`; `.python-version` и образ `python:3.12-slim` - 3.12.
  Матрица тестов в CI: 3.11 и 3.12. `ruff target-version = "py311"`, mypy `python_version = "3.11"`.
- Dockerfile - multi-stage: зависимости ставятся `uv sync --frozen --no-dev` в builder, в runtime
  копируется только `.venv`, процесс работает от пользователя `app` (uid 1000).
- Все образы и actions зафиксированы тегами (никаких `:latest`).

## Последствия

- Одинаковые версии инструментов локально, в pre-commit (хуки идут через `uv run`) и в CI.
- Образ небольшой и собирается с кэшем; пересборка при изменении только `src` быстрая.
- 3.13 пока не входит в матрицу CI. Синтаксис ограничен возможностями 3.11 (`StrEnum` и `Self`
  из `typing` допустимы, конструкции вроде `type X = ...` из 3.12 не используются).
